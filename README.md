Each folder is a self-contained page. To view one locally, run a web server from the repository root and open the folder:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/liverpool-v-newcastle/
```

With GitHub Pages turned on (Settings → Pages → deploy from `main`, root folder), each page is at `https://puetznicklas.github.io/england-soccer-tickets/<folder>/`.
